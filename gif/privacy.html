DNRB 워크스페이스의 GIF 메이커에서 만든 GIF 파일을 구글 드라이브에 저장하는 사내 전용 도구예요. 워크스페이스 관리자만 구글 계정을 연결하고 저장할 수 있고, 외부 고객은 쓰지 않아요.

구글 계정에서 받는 정보

  • 연결한 구글 계정의 이메일 주소 — 어느 계정이 연결되어 있는지 관리자 화면에 보여 주는 데만 써요.
  • 구글 드라이브 접근 권한(연결 증표) — 암호화해서 서버에만 보관해요. 화면이나 다른 사람에게 보이지 않아요.

구글 드라이브에서 하는 일

  • 미리 정해 둔 폴더 아래의 폴더 이름을 읽어요(저장할 곳을 고르기 위해).
  • 그 폴더 아래에 새 폴더를 만들고, GIF 파일을 만들거나 같은 이름 파일의 내용을 바꿔요.
  • 파일을 지우지 않고, 정해 둔 폴더 밖의 파일은 읽거나 바꾸지 않아요.

정보를 쓰는 범위

구글 API로 받은 정보는 위 기능을 제공하는 데만 써요. 광고에 쓰지 않고, 다른 회사나 사람에게 넘기거나 팔지 않으며, 사람이 내용을 들여다보지 않아요. 이 앱의 구글 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따라요.

보관과 삭제

  • 관리자가 GIF 메이커에서 [연결 끊기]를 누르면 구글 쪽 동의를 거두고, 서버에 보관한 연결 증표와 이메일 주소를 바로 지워요.
  • 구글 계정의 "서드 파티 앱 및 서비스" 설정에서도 언제든 연결을 끊을 수 있어요.
